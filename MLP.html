参数如何学习

下面是核心步骤：先计算预测，再把误差传回隐藏层更新参数。

# 前向传播
hidden  = sigmoid(X @ W1 + b1)
pred    = sigmoid(hidden @ W2 + b2)

# 反向传播
error      = pred - y
grad_out   = error * pred * (1 - pred)
error_hidden = grad_out @ W2.T
grad_hidden  = error_hidden * hidden * (1 - hidden)

# 按学习率更新参数
W2 -= lr * (hidden.T @ grad_out) / len(X)
W1 -= lr * (X.T @ grad_hidden) / len(X)

04

一轮训练里发生了什么

训练由四个反复循环的步骤组成，每次都让参数朝误差更小的方向挪动一点。

1

前向计算

当前权重把四个输入映射为四个 logits。

2

计算损失

二元交叉熵衡量输出与目标之间的距离。

3

反向传播

链式法则求出每个权重对损失的梯度。

4

Adam 更新

结合梯度的一阶、二阶动量调整每个参数。
